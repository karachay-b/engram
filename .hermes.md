# `.hermes.md` — Kontext für Hermes Agent

Zwei Repos, eine Aufgabe: **Der Nutzer lernt, die Engine merkt sich den Stand.**
`karachay-b/engram` (dieses Repo, öffentlich) ist die Lern-Engine plus die
Verdrahtung für zwei Plattformen; `karachay-b/engram-learning` (privat) trägt den
Lernstand. Details zu beiden: `CLAUDE.md` in diesem Repo.

**Auf Hermes wird gelernt, nicht am Setup gearbeitet.** Das Profil `engram` führt
`/engram-learn`, `/engram-review`, `/engram-coach`, `/engram-source` und
`/engram-status` aus und pusht den Lernstand nach jedem Turn nach `main`.
Upstream-Merges, Refactorings und Änderungen an `.claude/`/`.hermes/` laufen
weiter über Claude Code — dort liegen die Regeln, hier werden sie nur gelesen.

Die bindenden Übersetzungen (was auf Hermes anders läuft als in Claude Code):
`.hermes/PLATTFORM.md`. Diese Datei hat in Hermes' Kontextdatei-Priorität eine
höhere Stelle als `CLAUDE.md` und ersetzt sie deshalb in Sessions, deren
Arbeitsverzeichnis in diesem Repo liegt — absichtlich: `CLAUDE.md` beschreibt
Claude Codes eigene Hook- und Bootstrap-Mechanik, die hier nicht gilt.
